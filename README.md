# Slutprojekt

En enkel samling kemisidor med korta förklaringar och små quiz. Innehållet ligger i Html-filer/, styling i Css-filer/ och quiz-logiken i JavaScript-filer/slutprojekt.js.

Hur testa snabbt:

- Öppna projektmappen: `cd "h:\webbutveckling\Slutprojekt"`
- Starta en enkel server (valfritt): `python -m http.server 8000`
- Öppna webbläsaren på `http://localhost:8000`

Kort översikt (informellt):

- Html-filer: flera sidor (analytiskkemi, atomstruktur, kemiskareaktioner, osv.). Varje sida har begrepp, lite text och ett litet frågespel.
- JavaScript-filer/slutprojekt.js: rättar quiz, markerar korrekt med grönt och felvalda med rött.
- Css-filer/style.css: grundläggande stil.

Snabbtips:

- Vill du ändra quiz-svar, uppdatera objekten i slutprojekt.js.
- Lägg till/ändra nav-länkar i HTML-filerna om du flyttar index.html.
- För repetition: öppna filerna i VS Code och testa i webbläsaren.
